# Code of Conduct

This applies to everyone who takes part in this repository, including its issues and pull requests.

## Expected Behavior

- Be respectful and constructive
- Give feedback on the code, not the person
- Welcome questions and help others

## Unacceptable Behavior

- Harassment, insults or discriminatory language
- Personal attacks or threats
- Publishing someone's private information without permission

## Confidentiality

- Never post credentials, `.env` files, API keys or tokens in the repository, an issue or anywhere else.
- Never post WhatsApp session data, phone numbers or production database records.

## Reporting

Report unacceptable behavior privately to the maintainer through [GitHub](https://github.com/ars2k03). Report security issues as described in [SECURITY.md](SECURITY.md), not here.

## Enforcement

The maintainer may edit or remove comments, close issues, block accounts or take other action they consider appropriate.
